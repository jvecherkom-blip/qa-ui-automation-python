# QA Automation Framework

Test automation framework built with Python, Pytest and Selenium.

## Technologies

* Python
* Pytest
* Requests
* Selenium WebDriver
* JSON Schema
* Git

## Features

* REST API testing
* CRUD operations
* Authentication testing
* Positive and negative scenarios
* JSON schema validation
* UI automation with Page Object Model
* Explicit waits
* Logging

## Run tests

```bash
pip install -r requirements.txt
pytest
```
